Picabia app icon (figcraft.svg, figcraft-small.svg and every file derived from them in this
directory: figcraft-<size>.png, figcraft.ico, hicolor/). The file names are FigCraft's, kept so
upstream merges stay quiet.

Regenerate the derived files with `cargo xtask icon`.
